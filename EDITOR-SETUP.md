# Enable editing once in Google

The website is ready for editing, but saving is disabled until you connect the Google writer. Your current public Viewer link cannot authorize writes.

1. Open your spreadsheet with its owner account: https://docs.google.com/spreadsheets/d/1aTyJN0KQRLuGt96aPSGGGV8I8-KVqQmhut07MVEvook/edit
2. Select **Extensions → Apps Script**. Paste the contents of `GoogleSheetEditor.gs` into a new script file, replacing the empty starter function. If you already have scripts, preserve them and check there is no other `doPost` function. Save.
3. In **Project Settings → Script properties**, add a property named **EDITOR_KEY**. Use a unique random password of at least 32 characters, preferably generated by your password manager. Save the property. Keep this key private: anyone who knows it and the deployment URL can edit this spreadsheet through the app.
4. Select **Deploy → New deployment → Web app**. Set **Execute as: Me** and **Who has access: Anyone**. Deploy, authorize access to the spreadsheet using the owner account, and copy the **Web app URL** ending in `/exec`. Do not change the spreadsheet itself to public Editor access. If your organization disallows this deployment setting, its administrator must enable an appropriate authenticated connection instead.
5. Open the website, select **Connect editor**, and enter the web app URL and your editor key. The website verifies the connection and spreadsheet before enabling editing.

## Using the editor

- Select a university and page, edit its text fields, then select **Save to Google Sheet**.
- **Add university** creates a tab with the seven standard pages and three metadata fields.
- **Add page** creates a new row and immediately selects that page.
- **Add field** creates a new header column for the selected university, making it available on all of that university's pages.
- New rows, columns and tabs created directly in Google Sheets are detected with **Refresh data**, **Refresh universities**, or a page reload.
- Field names come from the first row. Page names come from column A. Custom field values occupy columns B onward.

The connection key stays in browser memory only and is cleared on reload or disconnect. It is sent in POST bodies over HTTPS on a deployed site, never in URLs or saved website files. Use HTTPS for remote hosting. The script requires the key for every request. Rotate it by changing the EDITOR_KEY script property if needed.

The editor checks a version fingerprint before each write and rejects outdated changes. Refresh after a conflict; copy your draft first if you wish to keep it. Existing formulas are protected from edits through this app. Script requests are serialized; direct edits made concurrently in the Google Sheets UI do not participate in the script lock, so avoid simultaneous editing during a save.

If a request fails or times out, it may have completed at Google already. Refresh before retrying. Changes are only shown as saved after Google's response confirms them. Google can impose Apps Script quotas.

## Running locally

Run `node preview.mjs` inside the downloaded website folder, then open http://127.0.0.1:4175. No npm installation is required. Keep the terminal running. `PORT` can override the port.

For Cloudflare deployment, run `node build.mjs`; the Worker entrypoint is `dist/server/index.js`. A static-only host cannot serve the editor or university-discovery APIs.

Google web app documentation: https://developers.google.com/apps-script/guides/web
